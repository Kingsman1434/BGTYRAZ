## 🌟 Возможности

### Для студентов:
- Регистрация по фамилии через `/start`.
- Запись в очередь на конкретное занятие (поддержка занятия нескольких мест, если разрешено).
- Просмотр всех активных очередей или только своих записей.
- Выход из очереди (в том числе частичный, если занято несколько мест).

### Для администраторов:
- Создание разовых и циклических (еженедельных) занятий.
- Привязка тем (topics) Telegram-группы к предметам через `/bind`.
- Ручное добавление студентов в очередь (включая тех, у кого нет Telegram).
- Управление пользователями: блокировка, изменение лимита мест, удаление.
- Модерация очередей: кик отдельных студентов, полная очистка, закрытие/открытие записи.

### Системные фичи:
- ⏰ **Автоуведомления:** Отправка актуальной очереди в чат за 1 час до начала пары (строго 1 раз).
- 🧹 **Автоочистка:** Удаление прошедших пар и их очередей через `SESSION_KEEP_MIN` минут после начала.
- ️ **Безопасность БД:** Использование `journal_mode=DELETE` и `busy_timeout` для предотвращения ошибок `database is locked` и `malformed`.
- 🌍 **Часовой пояс:** Жесткая привязка к `Europe/Moscow` (UTC+3) для корректной работы расписания.

## ⚙️ Технологический стек
- **Язык:** Python 3.10+
- **Библиотека:** `pyTelegramBotAPI` (`telebot`)
- **База данных:** SQLite3
- **ОС:** Linux (Ubuntu/Debian/Alpine)
- **Метод запуска:** `setsid` + `nohup` (фоновый процесс, независимый от SSH-сессии)
